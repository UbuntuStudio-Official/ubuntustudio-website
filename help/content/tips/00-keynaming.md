## Basic concepts
### modifier
- A modifier is a key that modifies the action of another key when pressed together.
- Common modifiers include `Ctrl`, `Alt`, `Shift`, and `Super` or `Meta`.
- the `Super`/`Meta` key is often referred to as the "Windows" key on many keyboards.

### keyboard shortcut
- A keyboard shortcut will be written in the format `<modifier>+<key>`,
- For example, `Ctrl+S` represents pressing the `Ctrl` key and the `S` key simultaneously.
